# 18650 UPS HAT

**Interface:** GPIO on Pi 5 — gpiochip4, line 17  
**Signal:** `POWER_FAIL` — active-LOW falling edge when mains power is lost  
**Power supply:** 18650 Li-ion cell(s), 5V regulated output  
**Power budget:** ~5A sustained @ 5V = 25W max; Pi 5 thermal limit 80°C

## Role
The sole emergency shutdown trigger in Phase 1. Provides:
1. Regulated 5V power to Pi 5 + Pico 2 via USB-C
2. `POWER_FAIL` GPIO assertion when battery backup engaged
3. ~15-second power window after POWER_FAIL for [[anti-death-node]] emergency sequence

## Phase 1 Constraints
- **No NVMe HAT** — all storage via /dev/shm only
- **No 12V DC-DC buck** — shutdown trigger exclusively from this GPIO
- **No automotive CAN** — no ignition-sense line

## GPIO Configuration
```cpp
// anti_death_node.cpp
gpiod::chip chip("/dev/gpiochip4");
gpiod::line line = chip.get_line(17);
line.request({"vigia_antideath", gpiod::line_request::EVENT_FALLING_EDGE, 0});
```
Falling edge = POWER_FAIL assert (active-low signal).
