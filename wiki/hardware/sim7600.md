# SIM7600 LTE CAT-4 Modem

**Interface:** USB (ECM mode → `usb0` Linux network interface)  
**AT command port:** `/dev/ttyUSB2`  
**Data port:** USB ECM → `usb0` (standard Linux TCP/IP stack)  
**LTE class:** CAT-4 (peak 150 Mbps DL, 50 Mbps UL — practical ~2 Mbps UL for emergency payload)

## ECM Configuration (one-time provisioning)
```
AT+CGDCONT=1,"IP","<operator_apn>"
AT+CUSBPIDSWITCH=9011,1,1   → switches to ECM mode, modem reboots
```
After reboot, Pi sees `usb0` via `cdc_ether` driver.

## Per-Boot Setup (vigia-edge.service `ExecStartPre`)
```bash
until ip link show usb0; do sleep 1; done
ip link set usb0 up && dhclient -1 -v usb0
ip route add <MQTT_BROKER_IP>/32 dev usb0  # only broker traffic over LTE
```

## Runtime Status Check (AntiDeathNode constructor)
- `AT+CREG?` → registration (1=home, 5=roaming)
- `AT+CSQ` → RSSI dBm (warn if < -100)
- `AT+CGACT?` → PDP context active

## Use in Emergency Sequence
- Pre-initialized LTE bearer at node startup (not during emergency window)
- [[aws-iot-mqtt]] client connects via `usb0` TCP socket using TLS 1.2 mTLS
- If bearer drops: `do_mqtt_connect()` retry within T+3→T+8s budget
- Phase 1: [[https-rest]] to AWS API Gateway (no SIM7600 required for initial testing)
- Phase 5: MQTT over SIM7600 ECM
