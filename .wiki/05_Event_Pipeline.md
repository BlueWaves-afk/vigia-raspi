# Event Pipeline

Covers the lifecycle of a pothole detection from Coordinator → ingest server.

## Component Map

```
Coordinator.midasLoop
      │ FusionOutput (rri ≥ threshold)
      ▼
EventPromoter::submit()   ← quality + dedup gates
      │ passed
      ▼
EventPromoter ring buffer  (wait-free SPSC, default 64 slots)
      │
      ▼
EventStore::syncLoop()     ← dedicated thread, 200 ms dequeue poll
      │ batch full OR interval elapsed
      ▼
EventStore::buildBatchJson()
      │ signer.hasKey() ?
      ├── YES → EventSigner::signEnvelope()  → HMAC-signed JSON
      └── NO  → hazardObservationToJson()    → plain JSON
      │
      ▼
SyncClient::postBatch()
      ├── VIGIA_HAVE_CURL  → HTTP POST to configured endpoint (10 s timeout)
      └── fallback         → stdout (dev mode)
```

## EventPromoter — Quality and Dedup Gates

`passesGates()` rejects observations that fail any of:

| Gate | Default threshold |
|------|-----------------|
| `rri < rri_threshold` | 0.5 (configurable) |
| `geometry_conf <= 0` | hard reject |
| `require_gps && !gps_valid` | requires GPS fix |
| `gps_fix_type < 2` | minimum 2D fix |
| `hdop > max_hdop` | 5.0 (configurable) |

`isDuplicate()` rejects observations within `dedup_radius_m` (default 15 m) of
any event recorded in the last `dedup_window_s` (default 30 s) using haversine
distance. The dedup ring holds `kDedupHistory = 16` entries — sufficient for
typical road-speed encounter rates.

## EventPromoter Ring Buffer (Lock-Free SPSC)

`ring_[ring_capacity_]` is a fixed-size array (`ring_.size()` from
`EventPromoter`'s `std::array` member). Producer (`submit()`) uses
`std::memory_order_release` on `tail_`; consumer (`try_dequeue()`) uses
`std::memory_order_acquire` on `tail_` and holds `consumer_mutex_` (MPSC
protection for syncLoop and any diagnostic readers). Full ring silently drops
the observation and returns `false`.

## EventStore Sync Loop

- `wait_dequeue()` polls with 200 ms timeout — low latency without busy-wait.
- Flushes when `batch.size() >= batch_size` OR `sync_interval_s` has elapsed.
- On stop, drains remaining promoter items before exiting to avoid data loss.
- `postWithCurl()` sets a 10-second timeout; failures log to stderr but do not
  crash or retry (retry is the server's responsibility via re-request).

## HazardObservation Layout

`HazardObservation` is a plain struct (no heap, no `std::string`) so it can live
in the ring buffer without allocation. Fields notable for safety:

- `device_id[32]` — always null-terminated by `EventPromoter::submit()` via
  `strncpy` + explicit `[31] = '\0'`.
- `event_id[16]` — UUIDv7 raw bytes generated by `generateEventId()` using
  `std::mt19937_64` seeded from `std::random_device`.
- `et_hash[32]` — filled only when `signed_et_valid` is true; zero otherwise.

## UUIDv7 Generation

`generateEventId()` sets bytes 0–5 from the 48-bit millisecond timestamp,
bytes 6–7 encode version 7 (0x7X), bytes 8–15 from `mt19937_64`. Variant bit
(`0x80`) is set on byte 8 per RFC 9562. Monotonically increasing within a
millisecond boundary — suitable for time-ordered database indexing.
